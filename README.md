# Atiendo CRM

Atiendo CRM es el sistema de atención por WhatsApp y agenda de visitas técnicas de un negocio de servicio técnico a domicilio en Colombia. Lo usan solo el dueño del negocio y su equipo.

La aplicación se conecta con el Google Calendar del propio negocio para no ofrecer a los clientes horarios que ya están ocupados y para anotar en el calendario las visitas que se agendan en el CRM.

Política de privacidad: <https://eddymir17-max.github.io/atiendo-crm-web/privacidad>
